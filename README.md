# Tłumacz - instalatory

Tu są wyłącznie gotowe instalatory aplikacji **Tłumacz** (tłumaczenia wspomagane AI).
Kod źródłowy jest w osobnym, prywatnym repozytorium.

## Pobieranie

Najnowsza wersja: zakładka **Releases** (po prawej) → najnowsze wydanie → sekcja *Assets*.

| System | Plik |
|---|---|
| Windows 10/11 | `Tlumacz_<wersja>_x64-setup.exe` |
| macOS (Apple M1/M2/M3/M4) | `Tlumacz_<wersja>_aarch64.dmg` |

## Instalacja

**Windows:** uruchom pobrany plik. Jeśli pojawi się „System Windows ochronił komputer”,
kliknij **Więcej informacji** → **Uruchom mimo to** (aplikacja nie ma płatnego certyfikatu).

**macOS:** otwórz plik `.dmg` i przeciągnij Tłumacza do folderu Programy. Za pierwszym razem
kliknij aplikację **prawym przyciskiem → Otwórz** (albo Ustawienia systemowe → Prywatność
i ochrona → „Otwórz mimo to”).

Po pierwszym uruchomieniu kreator przeprowadzi Cię przez konfigurację. Kolejne wersje
aplikacja wykrywa i instaluje sama - wystarczy potwierdzić.
